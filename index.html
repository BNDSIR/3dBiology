The "Selected Objects" Export Setting By default, Blender's glTF exporter is set to Limit to ➔ Selected Objects. If you forget to press A to select all objects in your viewport right before clicking export, Blender will only export whatever single nerve or brain structure you happened to click last. Solution: Press A to select everything in your scene before opening the export window, or change the exporter limit option to Visible Objects. 2. Disabled Viewport or Render Icons in the Outliner Z-Anatomy organizes the nervous system across multiple nested sub-collections (such as Central nervous system, Peripheral nervous system, Cranial nerves, and Sense organs). If a sub-collection has its Monitor icon (Disabled in Viewports/Renders) turned off in the top-right Outliner panel, Blender's exporter will silently skip every object inside it. Solution: Scan your Outliner and ensure every sub-collection under the nervous system has its eye and monitor icons fully enabled. 3. Collection Instances and Linked Data Z-Anatomy frequently relies on linked data and collection instances to save file space. Standard glTF exporters sometimes omit collection instances if they aren't realized into true geometry. Solution: Select your objects, go to the top menu under Object > Apply > Make Instances Real (if available), or make sure you copied raw mesh data rather than an empty container instance. 4. Unconverted Curves Many thin cranial nerves and nerve plexuses in Z-Anatomy are modeled as Blender CURVE datablocks rather than standard polygon MESH objects. If they lack thickness or weren't converted prior to export, the file will omit them entirely. Running the safe conversion script provided in the previous step automatically transforms these curves into solid 3D meshes so they export properly.
